# API 参考

本页用于练习**技术接口文档的写法**，展示如何描述请求方法、路径、参数和 JSON 返回结果。

!!! warning "仅供文档学习"
    下列 `/api/docs` 接口是模拟示例，**并没有真实的后端服务**。本项目是静态文档网站，不能通过这些地址调用接口。

## 1. 查询文档列表

该示例用于表示“获取站点中的文档条目”。

| 项目 | 说明 |
| --- | --- |
| 请求方法 | `GET` |
| 请求路径 | `/api/docs` |
| 功能 | 返回文档条目的列表 |
| 返回格式 | `application/json` |
| 是否可实际访问 | 否，示例接口 |

### 示例请求

```http
GET /api/docs HTTP/1.1
Host: example.test
Accept: application/json
```

### 示例响应

```json
{
  "code": 0,
  "message": "success",
  "items": [
    {"id": 1, "title": "使用指南", "slug": "guide"},
    {"id": 2, "title": "关于本项目", "slug": "about"}
  ]
}
```

### 响应字段解释

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `code` | 整数 | 模拟业务状态码，`0` 表示成功 |
| `message` | 字符串 | 结果说明 |
| `items` | 数组 | 文档条目列表 |
| `items[].id` | 整数 | 文档编号 |
| `items[].title` | 字符串 | 文档标题 |
| `items[].slug` | 字符串 | 文档标识 |

## 2. 查询单篇文档（扩展示例）

这个示例展示包含路径参数的请求写法。

- **请求方法**：`GET`
- **请求路径**：`/api/docs/{id}`
- **路径参数**：`id`，整数，代表文档编号

```http
GET /api/docs/1 HTTP/1.1
Host: example.test
```

模拟返回：

```json
{
  "id": 1,
  "title": "使用指南",
  "slug": "guide",
  "summary": "介绍本地构建、预览和自动部署的操作流程"
}
```

## 3. 为什么静态网站也要写 API 文档？

虽然 MkDocs 网站本身不提供这些接口，但接口说明是常见的技术文档形式。通过这一页，可以练习使用 Markdown 表格组织字段、使用代码块展示 JSON，以及清楚区分**示例**与**实际可访问的功能**。

要进行真正的自动部署操作，请返回 [使用指南](guide.md)；也可以回到 [首页](index.md) 了解整站结构。
